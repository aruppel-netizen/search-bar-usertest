# Поисковая строка на выдаче — юзтест (Pathway)

Тестовая сборка прототипа `search-bar-web`. Цель — понять, работает ли поисковая строка как основной вход в поиск на вебе. Десктоп, 100 респондентов, 2 задания.

## Ссылки для Pathway

Каждому заданию — своя ссылка. `r` — когорта: включает отправку событий и подписывает группу в таблице. Повторный запуск — новое значение (`r=pw2`).

| Задание | Старт | Ссылка |
| --- | --- | --- |
| 1 | Аренда квартир, как на проде | `https://aruppel-netizen.github.io/search-bar-usertest/?type=flat-rent&deal=rent&task=1&r=pw1` |
| 2 | Итог задания 1: покупка, вторичка, 2 комн., ремонт | `https://aruppel-netizen.github.io/search-bar-usertest/?type=secondary&deal=sale&rooms=2&repair=any&task=2&r=pw1` |

Без `r` прототип работает, но события не отправляет — для проверок и показа.

## Задания и правильные ответы

1. «Вы хотите купить 2-комнатную квартиру на вторичке с ремонтом. Найдите такие варианты и откройте подходящее объявление». Правильные ответы: id 12, 13, 14, 17, 18 (при сделке «Купить»).
2. «Теперь уточните запрос и найдите 2-комнатную квартиру на вторичке рядом с метро Сокол». Правильные ответы: id 13, 14.

**Финиш задания:** клик по сниппету открывает страницу объявления → кнопка «В избранное» на ней = ответ респондента. Финиш срабатывает на любом объявлении, правильность — в данных (`fav_add …|detail|t1:1|t2:0`, `test_finish …|id:13|t1:1|t2:1`). Сердечко на карточке в выдаче задание не завершает. После финиша — экран «Задание N выполнено» с метриками сессии (время, число поисков, открытых объявлений, id сессии): он попадает в запись экрана Pathway.

Дистракторы: 6, 19 — двушки-вторички без ремонта; 15, 16 — у Сокола, но 1 и 3 комнаты; 17, 18 — двушки с ремонтом у Аэропорта и Войковской; 4, 20 — двушки-новостройки у Аэропорта и Сокола. Данные — `data/test-listings.js`.

## Что изменено относительно прототипа

- Выдача фильтруется по сделке, типу, комнатам, цене, ремонту и метро; счётчики («Найдено», «Показать N» в модалках) — реальные.
- Строка понимает ремонт («с ремонтом», «евроремонт», «без ремонта») и станции метро с окончаниями («у Сокола»); подсказки предлагают станции («м. Сокол»).
- Клик по названию или фото открывает упрощённую страницу объявления.
- Подсказки и чипсы следующего слова знают «двушку / 2-комнатную / двухкомнатную», «во вторичке», «с ремонтом»; после «метро» чипсы дописывают станцию по первым буквам, подсказки — весь запрос со станцией.
- История поиска пустая, пагинации нет.

## События (Google-таблица)

`app_start` (задание, размер окна) · `search_submit` (текст + чем отправлен: enter / button / suggest) · `search_apply` (что строка разобрала) · `search_compose` (как собран запрос: `typed` — символов напечатано руками, `chip_chars` и `chips` — вставлено чипсами, `del`, `paste`, `autofill`, `sec` — время набора) · `search_shown` (что человек видел: набранный текст ‖ чипсы ‖ подсказки) · `suggest_pick` (тип, текст, позиция, что было набрано, мышь/клавиатура) · `chip_pick` (чипс, позиция, что было набрано) · `search_clear` · `allfilters_open` / `allfilters_apply` · `geo_apply` · `results` (число + состояние поиска, после каждого изменения) · `listing_open` (id, способ, позиция, подходит ли под задание 1/2) · `detail_back` · `phone_show` · `chat_tap` · `fav_add` / `fav_remove` (`|card` — сердечко в выдаче; `|detail|t1|t2` — ответ на странице объявления, завершает задание) · `screen_view` · `tap` (тепловая карта) · `test_finish`.

`tap`: `экран|x|y|элемент`. Экраны: `results`, `results+search`, `detail`, `allfilters`, `geo`. x — доля рамки 1440 px; y — px от верха страницы / 3000 (модалки — доля высоты окна). Элемент — канал: `search`, `search:chip:<чипс>`, `search:suggest:<тип>`, `search:clear`, `search:button`, `filter:<кнопка>`, `modal:<кнопка>`, `title`, `photo`, `phone`…

Логгер — `data/testlog.js` (адрес Apps Script — константа `ENDPOINT`).

## Проверка

`?log=1` — оверлей событий в углу. Перед запуском: открыть обе ссылки с `&log=1`, пройти задание, убедиться, что в оверлее `SEND ON`, есть `tap`, `results`, `listing_open`, `test_finish`, а строки появились в таблице.
